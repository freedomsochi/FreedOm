# Подключение Yandex AI Studio к FreeDom Agents

Провайдер уже подключён в коде через общий адаптер `agent/provider.ts`. Этот документ описывает, какие credentials нужны для безопасного запуска Preview.

## 1. Подготовить Yandex Cloud

1. Откройте Yandex AI Studio и выберите каталог, в котором будете запускать модели.
2. Используйте сервисный аккаунт с ролью `ai.languageModels.user` или более высокой ролью, разрешающей генерацию текста.
3. Создайте API-ключ с областью действия для выполнения запросов к Foundation Models / AI Studio.
4. Скопируйте секретное значение API-ключа и ID каталога. Секретное значение показывается при создании — сохраните его в менеджере паролей.
5. В каталоге моделей выберите доступную модель и скопируйте её полный URI. Пример URI из документации: `gpt://<folder-id>/yandexgpt-5.1`. Не используйте пример буквально: проверьте доступность модели в своём каталоге.

## 2. Добавить переменные в Vercel Preview

В Vercel откройте проект `freedom-agents` → Settings → Environment Variables. Добавьте следующие переменные, выбрав только **Preview**:

| Переменная | Значение |
|---|---|
| `YANDEX_API_KEY` | Секретное значение API-ключа |
| `YANDEX_FOLDER_ID` | ID каталога Yandex Cloud |
| `YANDEX_MODEL_URI` | Полный URI выбранной модели |

Не добавляйте эти значения в GitHub, исходники, чат или переменные с префиксом `NEXT_PUBLIC_`. Не включайте Production scope на этом этапе.

После добавления переменных создайте новый Preview deployment из рабочей ветки, чтобы окружение получило новые значения.

## 3. Что нужно проверить

1. Простой вызов модели: короткий ответ на русском языке.
2. Streaming: постепенная выдача ответа в Web Chat.
3. Function calling: модель должна запросить вызов тестового инструмента и корректно обработать его результат.
4. Делегирование: координатор должен вызвать хотя бы одного специалиста и получить его ответ.
5. Полный безопасный цикл: параллельный анализ специалистов, согласованный план и отчёт без записи в Production.

Сборка Eve, HTTP 200 и `/eve/v1/health` сами по себе не подтверждают эти сценарии.

## 4. Безопасность

- Не отправляйте API-ключ в переписке и не добавляйте его в коммиты.
- Используйте только Preview credentials до завершения тестов.
- Не переводите переменные в Production и не публикуйте Production без отдельного решения владельца.
- Проверьте квоты, стоимость и лимиты Yandex AI Studio до интенсивных запусков агентов.
- Если ключ случайно попал в лог, Git или сообщение, отзовите его и создайте новый.
