# FreeDom Agent Knowledge

Эта папка — версионируемая проектная память команды.

## Правила
- Записывать только подтверждённые факты и решения.
- Для каждого урока указывать ссылку на исходное ТЗ, commit/PR или доказательство тестирования.
- Разделять confirmed facts, hypotheses и open questions.
- Не копировать секреты, персональные данные гостей или платёжную информацию.
- Не переписывать историю решений: устаревшее правило помечать как superseded и указывать замену.
- Mentor анализирует и предлагает; Orchestrator проверяет; Programmer единственный применяет изменения.
