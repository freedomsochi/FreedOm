# FreeDom — визуальная система и правила дизайна

## Назначение
Единый набор принципов для согласованности публичных страниц. Документ не объявляет новые HEX-цвета, шрифты или размеры утверждёнными до сверки с актуальным CSS и реальными скриншотами.

## Художественное направление
- Природа и реальные фотографии — основа визуального языка.
- Атмосфера: свобода, пространство, тепло, жизнь сообщества, спокойная уверенность.
- Базовые визуальные ассоциации: лесная зелень, природные нейтральные оттенки, мягкое золото, светлые поверхности.
- Стекло, отражения, свечение и тени — тонкие вспомогательные эффекты, не самоцель.
- Избегать тёмного sci-fi, чрезмерного blur, сильного zoom/crop, хаотичных эффектов, дешёвых векторных иллюстраций и визуального шума.

## Обязательные принципы
1. Сначала содержание и иерархия, затем декоративные эффекты.
2. Реальные фотографии не заменять абстрактными изображениями без согласования.
3. Контраст и читаемость важнее прозрачности/стеклянности.
4. Не допускать резкой смены старых фонов при навигации и скачков фона при прокрутке.
5. Все интерактивные элементы должны иметь понятные hover/focus/active/disabled состояния.
6. Системный Reduce Motion должен уважаться.
7. Мобильная версия — полноценный сценарий, а не уменьшенная desktop-композиция.
8. Повторяющиеся элементы должны использовать общие tokens/components, если это безопасно и оправдано.

## Сетка и измерения
- Использовать CSS px/rem/%/vw/clamp() и фактические viewport.
- Для каждого существенного компонента указывать desktop/tablet/mobile.
- Не задавать «сантиметры» для web layout: физический размер не стабилен между дисплеями.
- Breakpoint выбирать по фактическому месту перелома композиции, а не только по популярному устройству.

## Типографика
Для каждого уровня заголовков и текста документировать font-family, fallback, font-size, weight, line-height, letter-spacing, max-width и цвет. Не менять глобальный шрифт без отдельного аудита.

## Изображения
Фиксировать точный путь, aspect ratio, object-fit, object-position, focal point, alt, fallback и мобильный crop. Не использовать один и тот же image query/asset для разных смысловых карточек, если это ухудшает точность.

## Motion
- Анимация должна помогать ориентироваться, а не отвлекать.
- Проверять duration, easing, interruptibility, touch/pointer, keyboard и reduced-motion.
- Не блокировать прокрутку/навигацию и не создавать неожиданного захвата жестов.
- На мобильных избегать дорогих blur/filter/large shadow на больших поверхностях без измерения производительности.

## Согласование
Изменения общей палитры, типографической шкалы, сетки, навигации и ключевой механики требуют предварительного согласования. Локальные обратимые исправления можно делать в рабочей ветке при наличии точной спецификации и тест-плана.
