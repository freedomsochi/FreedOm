# FreeDom — стандарт качества и QA gates

## Уровни проверки
1. **Static QA:** исходники, структура, lint/assertions, синтаксическая проверка. Отчёт указывает конкретные файлы и проверки.
2. **Build QA:** успешная сборка точного commit SHA. READY не означает browser/runtime PASS.
3. **Browser QA:** фактическое открытие Preview, сценарии, console/network, viewport, интерактивность. Указывать браузер и версию, URL, SHA и доказательства.
4. **Android QA:** реальное мобильное устройство/эмулятор, touch, scroll, viewport, ориентация, клавиатура.
5. **Integration/security QA:** только разрешённые read-only проверки. Live операции и обходы авторизации не проводить.

## Минимальная матрица
- 390×844: мобильная основная проверка.
- 768×1024: планшет.
- 1440×900: desktop.
- При необходимости 360×800 и 1280×800.
- Основные сценарии: главная→комнаты→доступность→форма (остановиться до submit); кухня→модалка (остановиться до отправки); вход→профиль→партнёры→покупки; страницы событий и бани; Space swipe/wheel; admin только без изменения данных.
- Состояния: initial, loading, success (только безопасный локальный/dry-run), empty, error, timeout, offline/rejected promise.

## QA record
Для каждого теста: ID, SHA, URL/build, browser/device, viewport, preconditions, steps, expected, actual, result PASS/FAIL/BLOCKED/NOT RUN, evidence, issue link.

## Release gates
- Любой P0/P1: NO-GO.
- Неизвестная авторизация финансовых/административных RPC: NO-GO для Production.
- Нет свежей сборки точного SHA: NO-GO.
- Нет browser QA ключевых пользовательских сценариев: NO-GO.
- Любой непроверенный live integration сценарий не объявлять принятым.
- Production GO возможен только после согласованного security verification, build и browser regression, владельческого подтверждения и явного разрешения пользователя.

## Безопасность
Не отправлять реальные формы, регистрации, бронирования, заказы, платежи, уведомления. Не менять DB, RLS, grants, RPC, Auth, права и пользовательские данные. Не использовать платные/лимитные инструменты, если лимит недоступен или это может вызвать списание.
